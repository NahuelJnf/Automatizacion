Automatización de pruebas con Selenium y Pytest
Descripción
Este proyecto consiste en la automatización de pruebas funcionales sobre la página web SauceDemo, utilizando Python, Selenium WebDriver y Pytest.

El objetivo es verificar el funcionamiento del inicio de sesión, la visualización de productos y los principales elementos de la interfaz.

Tecnologías utilizadas
Python
Selenium WebDriver
Pytest
WebDriver Manager
Google Chrome
Pruebas automatizadas
El proyecto incluye las siguientes pruebas:

Test	Descripción
Test 01	Verificar inicio de sesión
Test 02	Verificar inventario
Test 03	Comprobar que los productos sean visibles
Test 04	Validar nombres y precios de los productos
Test 05	Validar elementos de la interfaz
Test 06 al 08 no terminados

Para ejecutar todas las pruebas:
python -m pytest -v ./Test/test_saucedemo.py
En Windows PowerShell 

Resultados
Las pruebas permiten verificar el acceso al sistema, la carga del inventario, los nombres y precios de los productos y la visibilidad de los elementos principales de la interfaz.
